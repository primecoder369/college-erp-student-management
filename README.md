# College ERP – Student Management System

## Project Overview
This project is part of an Agile assignment. It aims to manage student information using a College ERP system.

## Objectives
- Register new students.
- View student details.
- Update student information.
- View student examination results.
- View student attendance records.

## Technologies and Tools
- Git
- GitHub
- Jira

## Agile User Stories
1. Student Registration
2. View Student Details
3. Update Student Details
4. View Student Results
5. View Student Attendance

## Repository Purpose
This repository demonstrates version control, commits, branching, merging, and collaboration using Git and GitHub.
## Student Attendance Feature

The system will allow students to view their attendance records, including classes attended, classes conducted, and attendance percentage.
